# Copy direction

B2B buyers scan for three things: what it is, whether it's for them, and whether it's proven. Write for that. Avoid the buzzwords in `ai-slop.md`.

## Headlines

| Pattern | Example shape | When |
|---|---|---|
| Outcome + audience | "Close your books in three days, not three weeks" | Default |
| Category + differentiator | "The [category] built for [audience / constraint]" | New buyers need a mental slot |
| Job to be done | "[Verb] every [object] from one place" | Platforms replacing several tools |
| Proof-led | "[Real number] [unit] [outcome]" | Only with a real, sourced number |
| Contrast | "[Old way]. Without [pain]." | Strong incumbent pain |

Rules: 6–12 words, sentence case, concrete nouns and verbs, no exclamation marks. Two-tone headlines put the accent on the outcome phrase only.

## Subheads

One or two sentences: what the product is + who it's for + the main mechanism. "Ramp-style": state the product category plainly ("Corporate cards, expenses and bill pay in one platform").

## CTA labels

| Motion | Primary | Secondary |
|---|---|---|
| Sales-led | Get a demo · Book a demo · Contact sales · Talk to sales | See how it works · Watch a demo |
| Self-serve | Start for free · Get started · Start free trial | Book a demo · View pricing |
| Hybrid | Get started | Get a demo |
| Service / industrial | Request a quote · Talk to an expert | Download catalogue · See services |
| Developer | Start building · Get API key | Read the docs · View on GitHub |

Rules: use the **same primary label** everywhere on the page. Start with a verb. Add a reassurance line under the button where true ("No credit card required", "14-day trial", "Response within one business day").

## Section titles

State the benefit, not the category. "Features" → "Everything finance needs to close faster". "Testimonials" → "Teams that closed faster". "Integrations" → "Works with the tools you already use" (+ the real count).

## Microcopy

- Form errors: what went wrong + how to fix it ("Enter a work email, like name@company.com").
- Empty states: what this is + why it's empty + the first action ("No invoices yet. Connect your accounting tool to import them.").
- Buttons in dialogs: name the action ("Delete project", not "OK").
- Pricing: units always ("per user / month"), annual savings as a percentage.
- Numbers: tabular figures, thousands separators, units, and a date or source for every claim.

## Placeholders

When real content is missing, write `[Customer quote: name, role, company]`, `[Metric from client]`, `[Logo]`. Never fill gaps with invented names, numbers or quotes.
